# Mochi's Little Sanctuary 🌙

A static, mobile-first comfort web app made with HTML, CSS and vanilla JavaScript. No backend, account, analytics, or tracking.

## Run locally
Open `index.html` in a browser. For the most reliable local testing, use a small static server or VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository (public repositories are simplest for GitHub Pages on plans that support it).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the Pages URL to appear. The app uses relative paths, so it works from a project subpath.

## Personalise Nash's letters
Edit `js/messages.js`. Replace the starter messages with words that sound like you. Keep private journal entries and personal secrets out of the repository: committed files in a public repository can be read by anyone.

## Privacy notes
- No backend, login, analytics, or tracking scripts.
- Preferences use localStorage in this browser on this device.
- LocalStorage is not encrypted and is not a secure vault. Anyone with access to the same browser profile/device may be able to see local data.
- GitHub Pages serves the website publicly. Do not commit private notes, private photos, credentials, or personal information.
- Optional sound is generated by the browser's Web Audio API after the user turns it on. Sound is off by default.
- No third-party scripts, fonts, images, or analytics are loaded. The app uses system font fallbacks and CSS-drawn artwork.

## Care note
This app offers gentle comfort and grounding, not diagnosis or treatment. It does not guarantee nightmares will stop. If nightmares are frequent, very distressing, or affect daily life, consider speaking with a qualified healthcare professional.
